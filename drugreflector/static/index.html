What This Tool Does

Use case

You start with a disease, perturbation, or cell-state transition signature and ask: which compounds are most aligned with this transcriptional pattern?

What the scores mean

Rank is the compound ordering, logit is the raw model score, and prob is a normalized confidence-like value from the model output.

中文说明

这个工具更像“候选药物优先级打分器”，不是原始单细胞数据的一站式分析流水线。 最适合已经整理出疾病或状态变化 signature 之后，做候选化合物初筛。

What it is not

This is not an end-to-end single-cell pipeline. It does not replace QC, normalization, differential expression, or biological validation.
